Tracker

A modular class HUD for WotLK. Procs, DoTs, cooldowns and resources in one compact cluster — one shared engine, a config per class.

Download Tracker View on GitHub

What is Tracker?

Tracker puts the handful of things you actually react to during a fight near the center of your screen, then gets out of the way when nothing is happening. It is built as one shared engine plus a small config per class, so it stays fast, clean and easy to extend.

Talent-aware

Every spell is filtered through your spellbook. Talents you never specced simply never appear, and the display survives a respec.

Smart auras

DoTs and debuffs show on the target with a live clock sweep. Player-only tracking never mistakes another caster's debuff or Rupture for yours, and cross-class buffs like Hysteria appear on every tracker.

Upkeep reminders

Maintained effects stay on screen and turn grey while missing, so you can see at a glance what needs refreshing.

Proc glow

Cooldowns light up the moment they come back up — a clean glow, with no flashing icons.

Resource & secondary bars

Rage, mana, energy and runic power, plus combo points and color-coded Death Knight runes.

Draggable & scalable

Unlock, drag, lock for click-through, and scale from 0.5 to 2.0. Position and scale are saved per character.

Install

  1. Download the latest release and extract it directly into World of Warcraft/Interface/AddOns/.
  2. Restart the client, or type /reload, then log in.
  3. Type /tracker unlock to drag the HUD, then /tracker lock to lock it in place.
CommandWhat it does
/tracker unlockUnlock and drag the HUD
/tracker lockLock in place, enable click-through
/tracker resetSnap back to default position
/tracker scale 1.2Resize the HUD (0.5 to 2.0)
/trackerShow all commands
